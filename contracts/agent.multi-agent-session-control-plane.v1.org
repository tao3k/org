** Hook-selected registered role choice plane

The deny rule selects a semantic role but the Hook event records only the rule
identity and generic recovery entrance. =asp session --agents choice-plane=
reloads the managed rule, resolves its role through the registry-derived
=agents.placeholders= projection, and opens only that role's pane. It accepts
neither an agent name, a task payload, nor a client selector. The selected
profile already defines the subagent's responsibility, while the active host is
derived from =CODEX_SESSION_ID=, =CODEX_THREAD_ID=, or =CLAUDE_SESSION_ID=.

Agent Session generation is owned only by native Host lifecycle receipts.
Workspace and provider generations are downstream capabilities and MUST NOT
gate ChoicePlane. If no durable namespace exists and the Host lifecycle surface
is unavailable, the pane enters terminal =host-surface-unavailable= and MUST NOT
repeat =CREATE_AND_REGISTER=.

The current Codex session id is the namespace join key. A Hook event may select
a role but is never session authority: a receipt from another root session must
not be reused. A call/resume action is available only when the current session
has a live, routable resident-child receipt whose binding exactly matches the
route and profile. If either the current-session receipt or the callable child
is absent, the namespace is absent for this session and exposes creation and
registration. Contract row numbers are internal ordering metadata and are never
rendered as Agent choices. Rust supplies typed state and bindings; this Org
contract owns the Agent-facing action language.

The ChoicePlane resolves exactly one =SESSION_STATE= from durable Host/session
authority before presentation. The six contract details are transition targets,
not a menu: exactly one matching row MUST be admitted and rendered; zero or
multiple matching rows are contract errors.

| resolved state | authoritative condition | rendered row |
| =registered= | durable namespace; live routable child; verified binding exactly matches route/profile | =CALL_RESUME_REGISTERED= (1) |
| =resumable= | current-session durable namespace with an explicit Host lifecycle receipt that permits reattachment | =RESUME_REGISTERED= (2) |
| =registration-required= | no durable namespace; native Host lifecycle surface available | =CREATE_AND_REGISTER= (3) |
| =achieved= | durable namespace terminally achieved its objective | =ACHIEVED= (4) |
| =blocked= | root, route, registry, binding authority, or another required invariant is invalid | =BLOCKED= (5) |
| =host-surface-unavailable= | no durable namespace; native Host cannot create/publish lifecycle receipt | =HOST_SURFACE_UNAVAILABLE= (6) |

Terminal/invariant states take precedence: =achieved= and =blocked= never fall
through to create or resume. For an absent namespace,
=host-surface-unavailable= overrides =registration-required=. Generation is
reported by the selected state but is not a workspace/provider execution gate.
