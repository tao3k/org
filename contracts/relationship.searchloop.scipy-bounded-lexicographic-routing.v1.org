** Definition

This query/assertion contract validates the parser-visible structure that the
RFC 10.05.64 semantic commitment consumes. It does not prescribe an outline
template and does not duplicate clause prose. Each assertion queries the Org
element graph for an exact normative heading and its stable clause marker.

Semantic source digests and dependency-frontier digests remain receipt-layer
facts. This contract establishes that those digests are taken from the intended
Org structure rather than from an unvalidated section with a coincidental path.
